## :dart: O guia para alavancar a sua carreira

> GraphQL é uma linguagem de consulta para APIs criada pelo Facebook em 2012 e aberta ao público em 2015: em vez de vários endpoints REST fixos, o cliente descreve exatamente os dados que precisa em uma única requisição, e o servidor responde só com isso — nem a mais, nem a menos. Hoje é usada por GitHub, Shopify, X e milhares de empresas para reduzir over-fetching, evoluir APIs com menos atrito entre times e dar autonomia para quem consome os dados. Este guia reúne documentação oficial, cursos gratuitos e pagos, livros, ferramentas do ecossistema (clientes, servidores, gateways de federação), projetos práticos, comunidades e um capítulo dedicado a usar IA na prática com GraphQL — tudo verificado e organizado para quem já sabe construir uma API REST e quer entender quando e como adotar GraphQL.

## 🚀 Por onde começar

1. Entenda o problema que o GraphQL resolve e leia a introdução oficial em [graphql.org/learn](https://graphql.org/learn/).
2. Veja o [roadmap.sh/graphql](https://roadmap.sh/graphql) para ter uma visão geral da ordem de estudo.
3. Faça o tutorial interativo e gratuito da Apollo, [Lift-off](https://www.apollographql.com/tutorials/lift-off-part1), ou o tutorial fullstack gratuito [How to GraphQL](https://www.howtographql.com/), disponível em várias stacks.
4. Explore um schema real sem instalar nada, usando o [Apollo Sandbox Explorer](https://studio.apollographql.com/sandbox/explorer) ou o [GraphiQL](https://github.com/graphql/graphiql).
5. Pratique consultas contra uma API pública, como a [Rick and Morty API](https://rickandmortyapi.com/documentation) ou a [API GraphQL do GitHub](https://docs.github.com/en/graphql).
6. Suba seu primeiro servidor com o [Apollo Server](https://www.apollographql.com/docs/apollo-server) ou gere uma API GraphQL automática a partir de um banco de dados com o [Hasura](https://hasura.io/).
7. Leia as boas práticas oficiais de [schema](https://graphql.org/learn/schema/) e de [paginação](https://graphql.org/learn/pagination/) antes de colocar algo em produção.
8. Entre em uma comunidade para tirar dúvidas, como o [GraphQL Brasil no Telegram](https://t.me/graphqlbrasil) ou o Discord oficial listado em [graphql.org/community](https://graphql.org/community/).

## 🤖 IA na prática

GraphQL e IA se encontram de duas formas: usar assistentes de IA para acelerar o trabalho com GraphQL, e usar o próprio GraphQL como camada de acesso a dados para agentes de IA.

**Para aprender e trabalhar com GraphQL**
- Cole o seu schema (SDL) em um assistente como o [GitHub Copilot](https://github.com/features/copilot), o [Cursor](https://cursor.com/) ou o [Claude Code](https://code.claude.com/docs/en/overview) e peça para ele gerar queries, mutations e resolvers de exemplo — depois rode contra o servidor real para conferir.
- Peça para a IA explicar um erro de resolver ou de resolução de tipos linha a linha, e sugerir onde adicionar `DataLoader` para resolver problemas de N+1 queries.
- Use um assistente de IA para gerar testes de integração cobrindo queries, mutations e casos de erro (campos nulos, autorização negada, paginação no limite).
- Depois de aceitar uma sugestão, rode o schema contra ferramentas como o [GraphQL Inspector](https://the-guild.dev/graphql/inspector) para garantir que nenhuma mudança quebrou um contrato existente.

**GraphQL como interface para agentes de IA**
- [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) — Padrão aberto, lançado pela Anthropic em 2024, para conectar assistentes de IA a ferramentas e fontes de dados; um schema GraphQL é uma forma natural de descrever essas ferramentas.
- [Apollo MCP Server](https://www.apollographql.com/docs/apollo-mcp-server) — Expõe operações GraphQL predefinidas de uma API existente como ferramentas utilizáveis por agentes de IA.
- [Repositório do Apollo MCP Server](https://github.com/apollographql/apollo-mcp-server) — Código-fonte aberto do servidor MCP oficial da Apollo.
- [SDK oficial de MCP em TypeScript](https://github.com/modelcontextprotocol/typescript-sdk) — Biblioteca para criar servidores e clientes MCP, útil para expor uma API GraphQL própria a um agente de IA.

**Limites e boas práticas**
- IA erra nomes de campos e argumentos que não existem no seu schema, principalmente em schemas grandes ou pouco documentados. Sempre valide contra o schema real antes de aceitar.
- Nunca exponha introspecção (`__schema`) nem o MCP Server em produção sem autenticação — um agente de IA com acesso irrestrito a mutations é tão perigoso quanto um usuário mal-intencionado.
- Prefira operações nomeadas e persistidas (persisted queries) quando expuser um schema para agentes automatizados: isso limita o que pode ser executado.

## 🎓 Certificações

Não existe uma certificação oficial de GraphQL mantida pela GraphQL Foundation — o ecossistema avalia principalmente projetos publicados e domínio prático do schema design. Alguns dos cursos já citados acima emitem certificado de conclusão, o que ajuda no currículo mesmo sem substituir portfólio: os três cursos da [Alura](https://www.alura.com.br/curso-online-graphql-criando-apis-schema-based) sempre emitem certificado aos assinantes, e a trilha [GraphQL do Pluralsight](https://www.pluralsight.com/paths/graphql) também gera certificado de conclusão dentro do plano pago.
